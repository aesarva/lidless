## Зачем Lidless

Большинство утилит против сна умеют одно: «не спать, пока крышка открыта». Lidless сделан для случаев, когда ты действительно отходишь от компьютера:

- **Работает с закрытой крышкой.** Закрываешь крышку — экран гаснет, а Mac продолжает сборку, загрузку, рендер, работу AI-агента, SSH-сессию или трансляцию по AirPlay. Если подключён внешний монитор, Lidless экраны не трогает.
- **Сам себя страхует.** Сессия останавливается при низком заряде, режим крышки ставится на паузу, если Mac нагрелся, а лимит времени не даст забытому ноутбуку перегреться в рюкзаке. При критическом нагреве с закрытой крышкой сессия завершается.
- **Никогда не ломает Mac.** Выход из Lidless возвращает обычный сон. Если приложение упадёт, его закроют принудительно или Mac перезагрузится посреди сессии, маленький сторож с правами root вернёт обычный сон в течение минуты. Единственная привилегированная команда, которую может выполнить Lidless, — `pmset -a disablesleep 0|1`.
- **Одно нажатие.** Табличка «В ЭФИРЕ» и есть кнопка: нажал — в эфире, нажал ещё раз — вышел из эфира. Для сессии с таймером на табличке идёт обратный отсчёт, для бессрочной — время в эфире.
- **Честно с первого взгляда.** В эфире значок в строке меню — маленькая горящая красная лампа; с таймером её свет «выгорает» вместе с оставшимся временем. Оранжевая точка значит, что нужно внимание.
- **Нативно и приватно.** SwiftUI + AppKit, универсальная сборка, никаких сетевых запросов, аналитики и аккаунтов.

## Возможности

| | |
|---|---|
| **Сессии** | 15 мин, 1 ч, 3 ч (пресеты настраиваются), *До…* — до заданного времени, или бессрочно (∞). Выбор длительности сразу запускает сессию или перезапускает текущую с новым сроком. |
| **Табличка** | Нажми (или Return), чтобы выйти в эфир и обратно. В эфире горит красным и показывает обратный отсчёт или время в эфире; вне эфира — тёмное стекло. |
| **Экран** | *Экран не гаснет* — экран горит; иначе экран может гаснуть, а Mac бодрствует. |
| **Режим крышки** | Mac работает с закрытой крышкой, экран при закрытии сразу гаснет. Нужно один раз установить помощника ([подробнее](#режим-крышки-и-помощник)). |
| **Приборы защиты** | Батарея и нагрев на панели как студийные шкалы, с отмеченным порогом батареи. |
| **Уведомления** | За 5 минут до конца сессии с таймером — с кнопками **+30 мин** и **+1 ч**; и когда правило защиты что-то остановило или поставило на паузу. |
| **Значок в строке меню** | Неброская линия вне эфира; горящая лампа в эфире; по желанию — оставшееся время рядом. |
| **Настройки** | Автозапуск при входе, длительность по умолчанию, пресеты, таймер в строке меню, старт сессии при запуске, пороги защиты, установка и удаление помощника, язык интерфейса. |
| **Языки** | Русский и английский; переключаются в «Настройки → Основные → Язык» независимо от языка системы. |

### Правила защиты

| Правило | По умолчанию | Что происходит |
|---|---|---|
| Низкий заряд | вкл, 20% (5–50%) | От батареи ниже порога сессия останавливается; ниже порога сессия не запустится. |
| Нагрев | вкл | При *серьёзном* нагреве режим крышки ставится на паузу (сессия идёт); при *критическом* с закрытой крышкой сессия останавливается. |
| Время с закрытой крышкой на батарее | вкл, 4 ч (30 мин–12 ч) | После этого режим крышки ставится на паузу. |

Каждое правило можно выключить или настроить в «Настройки → Защита».

## Установка

1. Скачай `Lidless.dmg` со страницы [Releases](https://github.com/aesarva/lidless/releases) и открой его.
2. Перетащи **Lidless** на ярлык **Applications** и запусти. Приложение живёт только в строке меню (без значка в Dock).
3. Релизы пока не подписаны Developer ID и не нотаризованы, поэтому Gatekeeper блокирует первый запуск. Нажми на приложение правой кнопкой → **Открыть** или выполни:

   ```sh
   xattr -dr com.apple.quarantine /Applications/Lidless.app
   ```

Нужна macOS 14 Sonoma или новее, Apple Silicon или Intel.

## Как пользоваться

1. Кликни по значку в строке меню.
2. Нажми табличку **В ЭФИРЕ** — или выбери длительность (15 мин, 1 ч, 3 ч, *До…*, ∞), чтобы стартовать сразу с ней.
3. Хочешь закрыть крышку? Включи **Режим крышки** (в первый раз Lidless попросит пароль администратора, чтобы установить помощника).
4. Нажми табличку ещё раз, чтобы выйти из эфира. Выход из Lidless тоже завершает сессию и возвращает обычный сон.

Повторный клик по значку или Esc закрывает панель. Правый клик по значку открывает быстрое меню.

## Режим крышки и помощник

Обычные сессии используют стандартный запрет сна macOS и ничего не требуют. Чтобы Mac не уснул с закрытой крышкой (без внешнего монитора), нужна команда `pmset -a disablesleep 1`, а она требует прав root. При первом включении режима крышки Lidless **один раз** спросит пароль администратора и установит:

| Путь | Назначение |
|---|---|
| `/etc/sudoers.d/lidless` | разрешает твоему пользователю выполнять `/usr/bin/pmset -a disablesleep 0` и `… 1` без пароля — и больше ничего |
| `/Library/PrivilegedHelperTools/app.lidless.watchdog.sh` | сторож, который возвращает обычный сон, если Lidless не запущен |
| `/Library/LaunchDaemons/app.lidless.watchdog.plist` | задача launchd `app.lidless.watchdog`, запускает сторожа раз в 60 секунд и при загрузке |

Файл-маркер `/Users/Shared/Lidless/lid-mode.marker` отмечает, что режим крышки включил именно Lidless. Если Lidless закрылся, упал или Mac перезагрузился посреди сессии, сторож видит маркер без работающего приложения и выполняет `pmset -a disablesleep 0`. Значение `disablesleep`, выставленное тобой вручную, Lidless не трогает.

Когда крышка закрывается в режиме крышки, Lidless гасит экран (`pmset displaysleepnow`, права не нужны) и не даёт Mac уснуть; когда крышка открывается, снова действует твой выбор для экрана.

### Модель безопасности

- **Правило узкое.** Правило sudoers разрешает ровно `pmset -a disablesleep 0|1`, только твоему пользователю и больше ничего. Перед установкой оно проверяется через `visudo`.
- **Пока Lidless не подписан Developer ID и не регистрирует помощника через `SMAppService`,** скрипты помощника копируются при установке из бандла приложения. Этот бандл доступен пользователю на запись, поэтому установка настолько надёжна, насколько надёжна скачанная копия Lidless. Устанавливай помощника только из копии, которой доверяешь.
- **После установки** правило sudoers и сторож лежат в каталогах, принадлежащих root. Удаление запускает `uninstall.sh` из бандла от root через запрос пароля, так что оно надёжно ровно настолько же, насколько бандл.
- **Если помощник сломается** при включённом режиме крышки (например, кто-то удалил файл sudoers), Lidless будет повторять попытку каждые 15 секунд и показывать оранжевую точку, пока обычный сон не вернётся; после выхода из Lidless сон вернёт сторож.

### Удаление

«Настройки → Помощник → Удалить», ввести пароль, затем удалить `Lidless.app`. Это удалит файл sudoers, сторожа, задачу launchd и маркер и вернёт обычный сон.

## Приватность

Lidless не делает сетевых запросов, не собирает аналитику и не требует аккаунта. Заряд батареи, источник питания, нагрев и датчик крышки он читает локально, только для правил защиты.

## Сборка из исходников

Нужны Xcode 16 или новее и

```sh
brew install xcodegen shellcheck
```

```sh
make test      # тесты пакета, shellcheck, тесты скрипта сторожа
make build     # сгенерировать проект Xcode и собрать (Debug)
make run       # собрать и запустить Debug-версию
make app       # Release, универсальная сборка (arm64 + x86_64), hardened runtime → build/Lidless.app
make dmg       # make app + dist/Lidless-<VERSION>.dmg без Developer ID (по умолчанию VERSION=0.2.0)
```

Подписанный релиз: с сертификатом **Developer ID Application** в связке ключей и один раз сохранёнными данными для нотаризации:

```sh
xcrun notarytool store-credentials Lidless --apple-id <you@example.com> --team-id <TEAMID>
scripts/release.sh 0.2.0     # сборка, подпись, нотаризация приложения и DMG, проверка Gatekeeper
```

Без сертификата: `scripts/release.sh 0.2.0 --unsigned` (или `make dmg`).

## Ручная проверка

Эти проверки требуют настоящего MacBook и пока не автоматизированы:

1. Сессия 15 минут с открытой крышкой и «экран может гаснуть»: экран гаснет, система не засыпает (`pmset -g assertions`).
2. Режим крышки, без внешнего монитора и зарядки, крышка закрыта 5 минут: в `pmset -g log` нет сна; SSH-сессия жива.
3. Принудительно закрыть Lidless в режиме крышки: в течение 60 секунд `pmset -g` показывает `SleepDisabled 0`.
4. Перезагрузка посреди сессии без автозапуска Lidless: после загрузки `SleepDisabled 0`.
5. Порог батареи выше текущего заряда: сессия останавливается, приходит уведомление.
6. Удаление помощника: файл sudoers, plist и скрипт удалены, `SleepDisabled 0`.

## Планы

- Автоматические триггеры: не спать, пока запущено приложение, при питании от сети, с монитором или в определённой Wi-Fi сети, во время загрузок, по расписанию.
- Интеграции: глобальная горячая клавиша, URL-схема, CLI, действия для «Команд».
- Статистика и виджеты: история сессий, виджет на рабочем столе, переключатель в Пункте управления.
- Подпись Developer ID, нотаризация и помощник через `SMAppService`.
