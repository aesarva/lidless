## 1. Цель и контекст

WakeUp — нативное приложение для строки меню macOS, которое не даёт Mac засыпать, в том числе с закрытой крышкой. Ориентир — Lungo, но функциональнее, красивее и безопаснее.

**Сценарии использования:** долгие задачи (загрузки, сборки, рендер, агенты), удалённый доступ (SSH, Screen Sharing, домашние сервисы), музыка/AirPlay, работа с внешним монитором.

**Аудитория:** автор, друзья, публичный GitHub. Developer ID появится позже — архитектура должна позволить перейти на подпись/нотаризацию без переделки.

**Этапы проекта** (у каждого свой цикл спецификация → план → реализация):
1. **Ядро** — этот документ.
2. Триггеры (приложение запущено, питание, монитор, Wi‑Fi, загрузка, расписание).
3. Интеграции (горячая клавиша, URL-схема, CLI, App Intents/Команды).
4. Статистика и виджеты (история сессий, виджет на рабочем столе, Центр управления).

Ядро проектируется так, чтобы этапы 2–4 были новыми источниками команд для `SessionController`, без изменения ядра.

**Критерий успеха этапа 1:** можно включить сессию на заданное время, закрыть крышку MacBook без внешнего монитора и зарядки — Mac продолжает работать; защита корректно останавливает сессию/режим крышки; после падения WakeUp система снова может засыпать не позже чем через 60 с.

## 4. Компоненты

### 4.1 WakeUpCore — чистая логика

**`Session`** — значение: `startedAt`, `endsAt: Date?` (nil = бессрочно), `keepDisplayOn: Bool`, `lidModeRequested: Bool`, `lidModeSuspendedReason: SafetyReason?`.

**`SessionController`** — единственная точка управления состоянием.
- Состояния: `off`, `active(Session)`.
- Команды: `start(duration:)`, `stop(reason:)`, `restart(duration:)`, `extend(by:)`, `setKeepDisplayOn(_:)`, `setLidMode(_:)`, `apply(SafetyDecision)`.
- Причины остановки (`StopReason`): `user`, `timerExpired`, `safety(SafetyReason)`, `appQuit`, `assertionFailed`.
- Время берётся из инжектируемого `Clock`; окончание определяется сравнением `now >= endsAt` (корректно после сна).
- Вызывает адаптеры: `SleepAssertionService`, `LidSleepService`, `Notifier`.
- Публикует состояние для UI (`@Observable`).

**`SafetyPolicy`** — чистая функция `evaluate(readings, session, settings) -> SafetyDecision`.
- `SafetyReadings`: `batteryLevel: Int?`, `onBattery: Bool`, `thermal: ThermalLevel` (`nominal/fair/serious/critical`), `lidClosed: Bool`, `lidClosedOnBatterySince: Date?`, `now`.
- `SafetyDecision`: `.none`, `.suspendLidMode(SafetyReason)`, `.stopSession(SafetyReason)`.
- `SafetyReason`: `lowBattery`, `thermal`, `lidOnBatteryLimit`, `helperUnavailable`.

**`StatusPresentation`** — выводит из состояния: вариант значка, текст таймера, модели плиток.

### 4.2 Системные адаптеры (протоколы в Core, реальные реализации в Core, фейки в тестах)

| Протокол | Реализация | Назначение |
|---|---|---|
| `SleepAssertionService` | IOKit `IOPMAssertionCreateWithName` | `PreventUserIdleSystemSleep` всегда в сессии; `PreventUserIdleDisplaySleep` при `keepDisplayOn` |
| `LidSleepService` | использует `PrivilegedBackend` | вкл/выкл `disablesleep`, ведение маркера |
| `PrivilegedBackend` | `SudoersBackend` (сейчас), `SMAppServiceBackend` (после Developer ID) | `status()`, `install()`, `uninstall()`, `setSleepDisabled(Bool)`, `isSleepDisabled()` |
| `PowerMonitor` | `IOPSNotificationCreateRunLoopSource` | заряд, питание от батареи/сети |
| `ThermalMonitor` | `ProcessInfo.thermalState` + `thermalStateDidChangeNotification` | уровень нагрева |
| `LidMonitor` | IORegistry `IOPMrootDomain` → `AppleClamshellState`, опрос каждые 15 с во время сессии | крышка открыта/закрыта |
| `Notifier` | `UNUserNotificationCenter` | уведомления с действиями |
| `LoginItem` | `SMAppService.mainApp` | автозапуск |
| `SettingsStore` | `UserDefaults` | настройки |

**`SafetyEngine`** (Core) — подписывается на мониторы, собирает `SafetyReadings`, ведёт `lidClosedOnBatterySince`, вызывает `SafetyPolicy` при каждом событии и по таймеру каждые 30 с во время сессии, передаёт решение в `SessionController.apply`.

### 4.3 UI (таргет App)

- Окно настроек — SwiftUI `Settings`-сцена / отдельное окно.

## 5. Поведение

### 5.1 Сессия

- Пресеты по умолчанию: 15 мин, 1 ч, 3 ч, «До…» (выбор времени), ∞. Список пресетов (кроме «До…» и ∞) редактируется в настройках.
- Длительность по умолчанию (для клика по главной плитке и пункта меню «Включить»): настройка, по умолчанию ∞.
- Клик по пилюле: если выкл — старт с этой длительностью; если активна — `restart` с новым сроком.
- Уведомление за 5 минут до окончания с действиями «+30 мин» и «+1 ч». Не показывается, если при старте до окончания меньше 5 минут.
- Окончание: снять assertions → если `disablesleep` включали мы, выключить → удалить маркер → уведомление (только при `timerExpired` и `safety`).
- Сессия не переживает перезапуск приложения. Настройка «Включать сессию при запуске WakeUp» (по умолчанию выкл) стартует новую сессию с длительностью по умолчанию.

### 5.2 Режим экрана

- Плитка «Экран»: «не гаснет» / «может гаснуть». Значение хранится в настройках (по умолчанию «может гаснуть») и применяется к текущей и будущим сессиям.

### 5.3 Режим закрытой крышки

- Плитка «Крышка»: переключатель, значение хранится в настройках (по умолчанию выкл). Действует только во время активной сессии: при старте сессии с включённым режимом — `setSleepDisabled(true)`, при окончании — `false`.
- Если помощник не установлен, клик по плитке предлагает установить его (запрос пароля). Отказ — плитка показывает «Нужен помощник», режим не включается.
- Если защита приостановила режим (`lidModeSuspendedReason != nil`), плитка показывает причину; повторный клик пользователя снимает приостановку (и сбрасывает счётчик лимита).

### 5.4 Защита

Правила (каждое включается отдельно, пороги настраиваются; все включены по умолчанию):

| Правило | Условие | Действие |
|---|---|---|
| Батарея | `onBattery && batteryLevel < порог` (по умолчанию 20%) | `stopSession(.lowBattery)` |
| Нагрев | режим крышки активен и `thermal >= serious` | `suspendLidMode(.thermal)` |
| Нагрев, критичный | `lidClosed && thermal == critical` | `stopSession(.thermal)` |
| Лимит крышки | режим крышки активен, `lidClosed && onBattery` непрерывно ≥ лимита (по умолчанию 4 ч) | `suspendLidMode(.lidOnBatteryLimit)` |

- Приоритет решений: `stopSession` важнее `suspendLidMode`.
- Счётчик лимита сбрасывается при открытии крышки или подключении питания.
- Если при попытке старта `onBattery && batteryLevel < порог` и правило батареи включено, сессия не стартует; главная плитка показывает «Заряд ниже N% — подключите питание или измените порог».
- Приостановка режима крышки длится до конца текущей сессии или до явного включения пользователем; настройка «Крышка» при этом не меняется.
- Каждое срабатывание — уведомление с причиной и состояние значка «защита».

### 5.5 Значок в строке меню (набор «пульс»)

| Состояние | Глиф |
|---|---|
| Выкл | ровная линия с точкой |
| Вкл, бессрочно | кардиограмма |
| Вкл, с таймером | кардиограмма в кольце прогресса (доля оставшегося времени) |
| Режим крышки активен | кардиограмма над горизонтальной линией |
| Защита / ошибка | кардиограмма с оранжевой точкой |

- Приоритет: защита → крышка → таймер → вкл → выкл.
- «Защита» показывается после срабатывания правила или ошибки помощника и сбрасывается при открытии поповера.
- Рядом со значком — текст оставшегося времени (`0:58`), если включён в настройках (по умолчанию выкл).
- Глифы — кастомные SF Symbols (template), автоматически адаптируются к светлой/тёмной строке меню. Оранжевая точка — единственный цветной элемент (отдельный слой, не template).

### 5.6 Поповер (вариант «плитки»)

- Главная плитка «Не сплю» во всю ширину: иконка, статус («ещё 58 мин · до 23:39» / «Бессрочно» / «Выключено»), переключатель.
- Сетка 2×2: «Экран», «Крышка», «Батарея» (заряд, «стоп при N%»), «Нагрев» (норма / повышен / высокий). Клик по «Батарея» и «Нагрев» открывает вкладку «Защита» в настройках.
- Ряд пилюль длительности; выбранная подсвечена.
- Внизу: «Настройки…» и «Выйти» (иконки).

### 5.7 Меню по правому клику

«Включить» / «Выключить», пресеты длительности, «Экран не гаснет ✓», «Закрытая крышка ✓», разделитель, «Настройки…», «Выйти WakeUp».

### 5.8 Настройки

- **Основные:** автозапуск при входе; длительность по умолчанию; редактор пресетов; показывать таймер в строке меню; включать сессию при запуске.
- **Защита:** для каждого правила — переключатель и порог (батарея: 5–50%, лимит крышки: 30 мин–12 ч; нагрев — без порога).
- **Помощник:** статус (не установлен / установлен / ошибка), «Установить», «Удалить», краткое объяснение, зачем нужен пароль.
- **О программе:** версия, ссылка на GitHub.

## 6. Помощник и сторож

### 6.1 SudoersBackend

**Установка** (один запрос пароля через `osascript -e 'do shell script "…" with administrator privileges'`, выполняется `Helper/install.sh` из бандла):
1. Сгенерировать `/etc/sudoers.d/wakeup` во временный файл:
   ```
   <user> ALL=(root) NOPASSWD: /usr/bin/pmset -a disablesleep 0, /usr/bin/pmset -a disablesleep 1
   ```
   Проверить `visudo -cf <tmp>`; при ошибке — прервать установку без изменений. Иначе установить с владельцем `root:wheel` и правами `0440`.
2. Скопировать `watchdog.sh` в `/Library/PrivilegedHelperTools/app.wakeup.watchdog.sh` (`root:wheel`, `0755`).
3. Установить `/Library/LaunchDaemons/app.wakeup.watchdog.plist` (`RunAtLoad`, `StartInterval` 60) и выполнить `launchctl bootstrap system …`.
4. Создать каталог маркера `/Users/Shared/WakeUp/` с владельцем — текущим пользователем. Маркер — `/Users/Shared/WakeUp/lid-mode.marker`: приложение пишет его без привилегий, сторож читает от root. Подделка маркера другим пользователем безопасна: худший исход — сброс `disablesleep` в 0 (системное значение по умолчанию). Сторож удаляет маркер через `rm -f` (симлинк удаляется сам, цель не затрагивается).

**Включение/выключение:** `sudo -n /usr/bin/pmset -a disablesleep 1|0`. Ненулевой код возврата — ошибка `helperUnavailable`.

**Статус:** установлен, если `sudo -n -l /usr/bin/pmset -a disablesleep 1` возвращает 0 и существуют plist и скрипт сторожа.

**Текущее значение:** парсинг `pmset -g` → строка `SleepDisabled  <0|1>`.

**Удаление** (один запрос пароля, `Helper/uninstall.sh`): `pmset -a disablesleep 0` (только если есть маркер), `launchctl bootout system/app.wakeup.watchdog`, удалить plist, скрипт, sudoers-файл, маркер.

### 6.2 Маркер

- Создаётся приложением перед `setSleepDisabled(true)`, удаляется после успешного `setSleepDisabled(false)`.
- Сторож и проверка при старте меняют `disablesleep` **только** при наличии маркера — ручные настройки пользователя не затрагиваются.

### 6.3 Сторож (`watchdog.sh`, root, раз в 60 с и при загрузке)

```
если маркер существует и `pgrep -x WakeUp` ничего не нашёл:
    pmset -a disablesleep 0
    удалить маркер
```
Поддерживает `--dry-run` (только печатает действие) для тестов.

### 6.4 Линии страховки

1. Штатный выход — `applicationWillTerminate` → `stop(.appQuit)`.
2. Старт приложения — маркер есть, сессии нет → `setSleepDisabled(false)`, удалить маркер.
3. Падение / Force Quit / выключение посреди сессии — сторож (≤60 с, или при загрузке системы).

### 6.5 SMAppServiceBackend (будущее)

XPC-демон в бандле, регистрируется через `SMAppService.daemon(plistName:)`. Реализует тот же `PrivilegedBackend`. Сторож и маркер сохраняются. Вне объёма этапа 1 — только интерфейс должен позволять подмену.

## 7. Обработка ошибок

| Ситуация | Поведение |
|---|---|
| Пользователь отменил установку помощника | плитка «Крышка» — «Нужен помощник», сессия без режима крышки |
| `visudo -cf` не прошёл при установке | установка прервана, ничего не изменено, алерт с текстом ошибки |
| `sudo -n pmset` вернул ошибку во время сессии | режим крышки не применяется, `SafetyReason.helperUnavailable`, значок «защита», уведомление «Режим крышки недоступен — переустановите помощника», сессия продолжается |
| `IOPMAssertionCreate` вернул ошибку | сессия не стартует, `StopReason.assertionFailed`, уведомление с кодом |
| Уведомления запрещены | работа без уведомлений, состояние «защита» на значке остаётся |

Логирование: `os.Logger(subsystem: "io.github.alexsarva.WakeUp", category: …)` — категории `session`, `safety`, `helper`, `ui`.

## 8. Тестирование

**Автоматические (Swift Testing, `swift test` в `Packages/WakeUpCore`):**
- `SessionController`: старт/стоп/рестарт/продление; истечение таймера, включая «проспали время окончания»; корректные вызовы фейковых `SleepAssertionService` и `LidSleepService`; маркер; обработка ошибок адаптеров; блокировка старта при низком заряде.
- `SafetyPolicy`: табличные тесты по каждому правилу, их сочетаниям и приоритету.
- `SafetyEngine`: ведение `lidClosedOnBatterySince` и его сброс.
- `StatusPresentation`: приоритет состояний значка, формат таймера, модели плиток.
- Генератор sudoers-строки: содержимое + `visudo -cf` на сгенерированном файле.
- Парсер вывода `pmset -g`.
- Скрипты: `shellcheck Helper/*.sh`; тест сторожа в `--dry-run` с подменённым путём маркера.

**Ручной чек-лист (реальный MacBook):**
1. Сессия 15 мин, крышка открыта, «экран может гаснуть» — экран гаснет, система не спит (`pmset -g assertions`).
2. Режим крышки, без монитора и зарядки, закрыть крышку на 5 мин — `pmset -g log` не показывает Sleep; SSH-сессия жива.
3. Force Quit WakeUp при активном режиме крышки — через ≤60 с `pmset -g` показывает `SleepDisabled 0`.
4. Перезагрузка посреди сессии без автозапуска WakeUp — после загрузки `SleepDisabled 0`.
5. Правило батареи с порогом выше текущего заряда — сессия останавливается, уведомление.
6. Удаление помощника — sudoers-файл, plist и скрипт удалены, `SleepDisabled 0`.

**UI:** SwiftUI Previews для всех состояний плиток и значка; UI-автотестов нет.
